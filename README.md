#HonotrsProjectFinal
To intall the application and run it: 
1. Install Android Studion(Narwhal) and install the small smartwatch emulator
2. after installing these, open the file in android studio and install the following tile services (WatchfaceTileservice, MaintileService, Stepcounttileservice)
3. Once the tile services are installed on the emulator, run the Mainactivity to launch the application.
4. Setup the age and the goal steps for the user
5. Once the simulation data is loaded, yo can then visualise the data uo until the most recent time on the application
